# TableBlock

A ready-made transactions table with row selection, a per-row action menu and built-in
pagination.

`TableBlock` has a fixed row shape rather than configurable columns. When you need
arbitrary columns, use [SearchableTableBlock](/blocks/searchable-table-block), or compose
`Table` directly from `@raydenui/ui`.

## Import

```tsx
import { TableBlock } from "@raydenui/ui/blocks";
```

## Usage

### Basic

Each row supplies the full set of fields the table renders.

```tsx
const rows = [
  {
    id: "1",
    name: "Ada Lovelace",
    email: "ada@example.com",
    initials: "AL",
    amount: "$1,200.00",
    paymentType: "Card",
    date: "12 Jun 2023",
    time: "10:24 AM",
    status: "Paid",
    statusColor: "success",
  },
];

<TableBlock rows={rows} />;
```

### Row actions

`onRowAction` fires with the row id when the kebab menu is activated. The control is
named after the row, so screen reader users know which row it affects.

```tsx
<TableBlock rows={rows} onRowAction={(rowId) => openMenuFor(rowId)} />
```

### Pagination

Pagination is controlled: pass `page` and `totalPages` and update them in `onPageChange`.

```tsx
const [page, setPage] = useState(1);

<TableBlock rows={rows} page={page} totalPages={8} onPageChange={setPage} />;
```

### Custom styling

```tsx
<TableBlock className="rounded-xl shadow-soft-lg" rows={rows} />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `rows` | `TableBlockRow[]` | — | Table rows (required) |
| `page` | `number` | — | Current page, 1-indexed |
| `totalPages` | `number` | — | Total pages |
| `onPageChange` | `(page: number) => void` | — | Page change handler |
| `onRowAction` | `(rowId: string) => void` | — | Row action (kebab menu) handler |
| `className` | `string` | — | Additional CSS classes |

### TableBlockRow

| Field | Type | Description |
|-------|------|-------------|
| `id` | `string` | Unique row identifier |
| `name` | `string` | Person's name |
| `email` | `string` | Email address, shown under the name |
| `initials` | `string` | Avatar initials |
| `amount` | `string` | Formatted amount |
| `paymentType` | `string` | Payment method label |
| `date` | `string` | Date label |
| `time` | `string` | Time label |
| `status` | `string` | Status label |
| `statusColor` | `"success" \| "warning" \| "error" \| "orange" \| "blue" \| "neutral"` | Status badge colour |

## Accessibility

- Selection checkboxes are named after their row, and the select-all control is named
  "Select all rows".
- The row action button is named `Actions for <name>`, using the row's own name.
- The action column has a visually hidden "Actions" heading, so the column is not empty
  for screen readers.
