# InvoiceDetailBlock

Inspect invoice lines, taxes, adjustments, the amount due, its status and the available
payment actions.

Plan idea 83, category **Finance & billing**. Status **experimental**, verification level
**unmeasured** — see [verification](#verification) before adopting it.

## Import

```tsx
import { InvoiceDetailBlock } from "@raydenui/ui/blocks";
import type { InvoiceLine, InvoiceAdjustment, InvoiceParty } from "@raydenui/ui/blocks";
```

## Usage

Amounts are **minor-unit integers** in the invoice's single `currency`. A negative amount is a
credit.

```tsx
const lines: InvoiceLine[] = [
  {
    id: "design",
    description: "Interface design",
    detail: "1–15 September 2026",
    quantity: 37.5,
    quantityUnit: "hours",
    unitPrice: 9500,
    amount: 356250,
  },
  { id: "credit", description: "Goodwill credit", amount: -15000 },
];

<InvoiceDetailBlock
  invoiceNumber="2026-114"
  status={{ label: "Past due", tone: "danger", description: "Payment was due on 20 September." }}
  currency="GBP"
  locale="en-GB"
  issuedOn="2026-09-01"
  dueOn="2026-09-20"
  billedTo={{ label: "Billed to", lines: ["Northwind Logistics", "24 Willow Lane", "London, N1 4AB"] }}
  billedFrom={{ label: "From", lines: ["Citrionus Ltd", "Registered in England 09876543"] }}
  lines={lines}
  subtotal={341250}
  taxes={[{ id: "vat", label: "VAT", detail: "VAT 20%", amount: 68250 }]}
  amountPaid={100000}
  amountDue={309500}
  amountDueNote="Payable within 30 days of issue."
  primaryAction={{ id: "pay", label: "Pay invoice", onClick: () => openPayment(), tone: "primary" }}
  actions={[{ id: "pdf", label: "Download PDF", href: "/invoices/2026-114.pdf" }]}
/>;
```

`amountDue` is **required and supplied, never derived from the lines**, so a rounding rule or a
credit the block does not know about cannot silently change it.

### Three different absences

| Situation                         | How to express it                                     |
| --------------------------------- | ----------------------------------------------------- |
| No invoice at all                 | `state="empty"` with `emptyTitle` / `emptyDescription`  |
| An invoice carrying no lines      | `lines={[]}` with `linesEmptyTitle` / `linesEmptyDescription` |
| A filtered view with no matches   | `lines={[]}` with your own no-matches wording in the same props |

```tsx
<InvoiceDetailBlock
  currency="GBP"
  amountDue={0}
  lines={[]}
  linesEmptyTitle="This invoice has no lines yet"
  linesEmptyDescription="Add a line to issue it."
  linesEmptyAction={{ id: "add", label: "Add a line", onClick: () => addLine() }}
/>
```

### Long invoices

Beyond `maxVisibleLines` (default 12) the table body moves into a bounded, focusable, vertically
scrolling region, so a long invoice cannot lengthen the page without limit.

At enlarged text sizes, table columns can scroll horizontally inside a named, keyboard-focusable
area. The page itself stays within its container, and totals remain outside the scrolling table.

```tsx
<InvoiceDetailBlock
  currency="GBP"
  amountDue={309500}
  lines={fortyLines}
  maxVisibleLines={12}
  scrollRegionMaxHeight="26rem"
/>
```

### Unknown amounts and translation

```tsx
<InvoiceDetailBlock
  currency="EUR"
  locale="nl-NL"
  amountDue={null}
  unknownLabel="Niet beschikbaar"
  lines={lines}
  linesLabel="Factuurregels"
  columnLabels={{
    description: "Omschrijving",
    quantity: "Aantal",
    unitPrice: "Stukprijs",
    amount: "Bedrag",
  }}
/>
```

### Loading, error and empty

```tsx
<InvoiceDetailBlock currency="GBP" amountDue={null} lines={[]} state="loading" />
```

```tsx
<InvoiceDetailBlock
  currency="GBP"
  amountDue={null}
  lines={[]}
  state="error"
  errorTitle="This invoice could not be loaded"
  onRetry={() => refetch()}
/>
```

```tsx
<InvoiceDetailBlock
  currency="GBP"
  amountDue={null}
  lines={[]}
  state="empty"
  emptyTitle="No invoice selected"
  emptyAction={{ id: "choose", label: "Choose invoice", onClick: () => openList() }}
/>
```

### Payment the viewer may not make

`primaryAction` is a `FinanceAction`, so a payment the viewer is not permitted to make renders
disabled with the reason visible rather than as a dead button.

```tsx
<InvoiceDetailBlock
  currency="GBP"
  amountDue={309500}
  lines={lines}
  primaryAction={{
    id: "pay",
    label: "Pay invoice",
    unavailableReason: "Only a billing administrator can pay an invoice.",
  }}
/>
```

### InvoiceLine

| Member         | Type                | Description                                             |
| -------------- | ------------------- | ------------------------------------------------------- |
| `id`           | `string`            | Required, stable.                                        |
| `description`  | `ReactNode`         | Required.                                                |
| `detail`       | `ReactNode`         | A second line, e.g. a period or a SKU.                    |
| `quantity`     | `number \| null`     | Decimals allowed, e.g. 7.5 hours. `null` is unknown.       |
| `quantityUnit` | `string`            | Unit `quantity` is measured in.                            |
| `unitPrice`    | `FinanceMoneyValue` | Minor-unit integer, or `null` for unknown.                 |
| `amount`       | `FinanceMoneyValue` | Required. Negative is a credit line.                       |

### InvoiceAdjustment

`{ id, label, amount, detail? }`. A negative `amount` is a credit or discount; `detail` carries
the rate or basis, e.g. "VAT 21%".

### InvoiceParty

`{ label?, lines }`, where `lines` are address or identity lines in reading order.

## States

- **default** — the invoice.
- **loading** / **error** — with an optional retry control.
- **empty** — no invoice at all.
- **lines empty** — an invoice carrying no lines, or a filtered view with no matches, in your
  own wording.
- **unknown amount** — per amount, from `null`.
- **payment unavailable** — a permission-blocked `primaryAction`.

## Verification

**No verification run exists for this block yet.** The batch that built it had its run
interrupted and is repeating it, and its batch report (`docs/blocks-batch-d.md`) did not exist
when this page was written. This page was reconciled against the block's public TypeScript
types and its 14 story exports, and the block resolves from a built package with its types —
nothing more.

Not verified: layout at any width, contrast in either mode, keyboard flows, theme overrides, a
screen-reader pass, any non-Chromium engine, operating-system text-size settings, or physical
devices. The bounded line-scroll region in particular has not been measured.

## Known limitations

- `amountDue` is supplied, never derived from the lines.
- The block takes no payment. `primaryAction` hands that to your application.
- Every amount in one invoice shares a single currency and locale.
