# Blocks

24 reusable blocks for application UI, marketing, commerce, and finance. Import components and their TypeScript types from `@raydenui/ui/blocks`. The library is expanding toward the approved 100-block plan across 12 categories.

## Import

```tsx
import {
  ApplicationShellBlock,
  PageHeaderBlock,
  WorkspaceSwitcherBlock,
  CommandPaletteBlock,
  NotificationsBlock,
  LoginBlock,
  TableBlock,
  QuickSendBlock,
  RecentTransactionsBlock,
  EmptyStateBlock,
  SearchableTableBlock,
  HeaderBlock,
  CreateAccountBlock,
  KpiOverviewBlock,
  ProfileSettingsBlock,
  TaskListBlock,
  ProductHeroBlock,
  FeatureOverviewBlock,
  PricingPlansBlock,
  SiteFooterBlock,
  ProductCollectionBlock,
  ProductDetailBlock,
  ShoppingCartBlock,
  CheckoutReviewBlock,
} from "@raydenui/ui/blocks";
```

Or import individually:

```tsx
import { LoginBlock } from "@raydenui/ui/blocks";
```

## Available Blocks

| Block                                                        | Description                               |
| ------------------------------------------------------------ | ----------------------------------------- |
| [NotificationsBlock](/blocks/notifications-block)            | Notification list with read/unread states |
| [LoginBlock](/blocks/login-block)                            | Authentication form with social providers |
| [TableBlock](/blocks/table-block)                            | Data table with header and pagination     |
| [QuickSendBlock](/blocks/quick-send-block)                   | Quick money transfer interface            |
| [RecentTransactionsBlock](/blocks/recent-transactions-block) | Transaction history list                  |
| [EmptyStateBlock](/blocks/empty-state-block)                 | Empty state with illustration and CTA     |
| [SearchableTableBlock](/blocks/searchable-table-block)       | Table with search and filters             |

### Navigation and shells

ApplicationShellBlock, PageHeaderBlock, WorkspaceSwitcherBlock and CommandPaletteBlock compose into a responsive application frame. See [navigation blocks](/blocks/navigation) for public contracts and examples.

### Commerce batch

| Block                  | Purpose                                                             |
| ---------------------- | ------------------------------------------------------------------- |
| ProductCollectionBlock | Search, category filters, sorting, and product actions              |
| ProductDetailBlock     | Product options, stock limits, quantities, and add-to-cart callback |
| ShoppingCartBlock      | Controlled cart items, quantities, removal, and totals              |
| CheckoutReviewBlock    | Delivery, payment summary, order review, and confirmation states    |

See [commerce blocks](/blocks/commerce) for a complete integration example.

## Customization

Blocks accept a `className` prop for custom styling:

```tsx
<TableBlock className="rounded-xl shadow-soft-lg" rows={rows} />
```

For deeper customization, consider using the individual components directly from `@raydenui/ui`.
