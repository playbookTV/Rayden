## Quick Start

The fastest way to get started is with `create-rayden-app`:

```bash
npx create-rayden-app my-app
```

Choose from 6 templates (blank, minimal, landing, dashboard, ecommerce, blog) with Vite or Next.js. See the [create-rayden-app guide](/getting-started/create-rayden-app) for all options.

### Manual Installation

```bash
npm install @raydenui/ui
```

Import the styles in your app's entry point:

```tsx
// App.tsx or main.tsx
import "@raydenui/ui/styles.css";
```

### Use Components

```tsx
import { Button, Input, Badge } from "@raydenui/ui";

function App() {
  return (
    <div className="flex flex-col gap-4 p-8">
      <Input
        label="Email"
        placeholder="you@example.com"
        helperText="We'll never share your email"
      />
      <Button variant="primary" size="lg">
        Subscribe
      </Button>
      <Badge color="success">Active</Badge>
    </div>
  );
}
```

## Built for your workflow

Rayden brings the [Rayna UI](https://www.raynaui.com/) design system to React with 33+ components, TypeScript types, and Tailwind CSS v4. Import only the components you need, or use [AI integration](/ai-integration) to help assemble them.
