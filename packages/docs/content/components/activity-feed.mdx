# ActivityFeed

Show a timeline of user activity — comments, uploads and status changes — built from
`ActivityItem` rows with optional `ActivityContent` blocks.

## Import

```tsx
import { ActivityItem, ActivityContent, Avatar } from "@raydenui/ui";
```

## Usage

### Basic

Every row needs an `avatar` and `text`. `text` takes nodes, so names and links can be
emphasised inline.

<Preview>
  <ActivityItem
    avatar={<Avatar type="initials" initials="DA" size="sm" />}
    text={
      <>
        <span className="font-medium text-grey-700">David</span> left a comment on{" "}
        <span className="font-medium text-primary-400">Site redesign</span>
      </>
    }
    date="Thurs 21, 2023"
    time="10 mins"
  />
</Preview>

```tsx
<ActivityItem
  avatar={<Avatar type="initials" initials="DA" size="sm" />}
  text={
    <>
      <span className="font-medium text-grey-700">David</span> left a comment on{" "}
      <span className="font-medium text-primary-400">Site redesign</span>
    </>
  }
  date="Thurs 21, 2023"
  time="10 mins"
/>
```

### With a link and badge

`link` renders a single action in the meta row; `badge` adds a short label beside it.

<Preview>
  <ActivityItemLinkDemo />
</Preview>

```tsx
<ActivityItem
  avatar={<Avatar type="initials" initials="AD" size="sm" />}
  text={
    <>
      <span className="font-medium text-grey-700">Ada</span> requested a review
    </>
  }
  time="10 mins"
  link={{ label: "View request", onClick: () => {} }}
  badge="#Marketing-Design"
/>
```

### With a content block

Pass `ActivityContent` as children to attach a file, image or message block.

<Preview>

      <>

    time="2 hours"

      variant="file"
      icon="file-alt"
      title="Project brief.pdf"

      date="11 Sept 23"

  </ActivityItem>
</Preview>

```tsx
<ActivityItem
```

### Timeline

`connector` draws the vertical line between rows. Use `"top"` for the first row,
`"middle"` for the ones between and `"last"` for the final row.

      time="Just now"

## Props

### ActivityItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `avatar` | `ReactNode` | — | Avatar element (required) |
| `text` | `ReactNode` | — | Primary text content (required) |
| `unread` | `boolean` | `false` | Shows the unread dot |
| `date` | `string` | — | Date label |
| `time` | `string` | — | Time label, right-aligned |
| `link` | `{ label: string; href?: string; onClick?: () => void }` | — | Link button in the meta row |
| `badge` | `string` | — | Badge text in the meta row |
| `connector` | `"top" \| "middle" \| "last"` | — | Connector line for timeline layouts |
| `children` | `ReactNode` | — | Content block, e.g. `ActivityContent` |

### ActivityContent

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `ActivityContentVariant` | — | Content variant (required) |
| `contentStyle` | `ActivityContentStyle` | — | Visual style wrapper |
| `icon` | `ReactNode \| IconName` | — | Leading icon, file variant |
| `title` | `string` | — | File name |
| `size` | `string` | — | File size |
| `fileType` | `string` | — | File type label |
| `date` | `string` | — | File date |

## Accessibility

- Put the actor and the action in `text` so the row reads as a sentence; do not rely on
  the avatar alone to say who acted.
- Give the `Avatar` an `alt` describing the person.
- Use `link` rather than making the whole row clickable, so the action is reachable by
  keyboard and has a name.
