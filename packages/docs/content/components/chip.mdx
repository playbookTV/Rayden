# Chip

Chips are compact elements for tags, filters, and selections with optional close or filter actions.

## Import

```tsx
import { Chip } from "@raydenui/ui";
```

## Usage

### Input Chip (with close button)

<Preview>
  <Chip variant="input">
    React
  </Chip>
  <Chip variant="input">
    TypeScript
  </Chip>
  <Chip variant="input">
    Tailwind
  </Chip>
</Preview>

```tsx
<Chip variant="input" onClose={() => removeTag()}>
  React
</Chip>
```

### Filter Chip (with chevron)

<Preview>
  <Chip variant="filter">
    Category
  </Chip>
  <Chip variant="filter">
    Status
  </Chip>
</Preview>

```tsx
<Chip variant="filter" onClick={() => openFilter()}>
  Category
</Chip>
```

### States

<Preview>
  <Chip variant="input">Default</Chip>
  <Chip variant="input">Selected</Chip>
  <Chip variant="input" disabled>Disabled</Chip>
</Preview>

```tsx
// Default
<Chip variant="input">Default</Chip>

// Focused
<Chip variant="input">Selected</Chip>

// Disabled
<Chip variant="input" disabled>Disabled</Chip>
```

### With Avatar

<Preview>
  <Chip variant="input" icon="user-circle">
    John Doe
  </Chip>
</Preview>

```tsx
<Chip variant="input" icon="user-circle" onClose={() => {}}>

```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"input" \| "filter"` | `"input"` | Chip variant |
| `disabled` | `boolean` | `false` | Disables the chip |
| `onClose` | `() => void` | — | Close button handler (input variant) |
| `onClick` | `() => void` | — | Click handler (filter variant) |
| `className` | `string` | — | Additional CSS classes |

## Accessibility

- Uses semantic `<button>` element
- Close button has proper aria-label
- Keyboard accessible
