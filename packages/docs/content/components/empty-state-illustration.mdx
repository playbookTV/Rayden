# EmptyStateIllustration

Ready-made SVG illustrations for empty states, onboarding and zero-data screens.

## Import

```tsx
import { EmptyStateIllustration } from "@raydenui/ui";
```

## Usage

### Basic

`name` is required and selects the illustration.

<Preview>
  <EmptyStateIllustration name="inbox" />
</Preview>

```tsx
<EmptyStateIllustration name="inbox" />
```

### Size

`size` is a number in pixels, applied to both width and height. It defaults to `150`,
the native SVG size.

<Preview vertical>
  <EmptyStateIllustration name="gallery" size={96} />
  <EmptyStateIllustration name="gallery" size={150} />
  <EmptyStateIllustration name="gallery" size={220} />
</Preview>

```tsx
<EmptyStateIllustration name="gallery" size={96} />
<EmptyStateIllustration name="gallery" size={150} />
<EmptyStateIllustration name="gallery" size={220} />
```

### Monochrome

Set `colored={false}` for the grey variant, useful on busy or tinted backgrounds.

<Preview vertical>
  <EmptyStateIllustration name="team" />
  <EmptyStateIllustration name="team" colored={false} />
</Preview>

```tsx

```

`palette` replaces the default primary palette on coloured illustrations. Provide 11
hex colours, lightest to darkest. It is ignored when `colored` is `false`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `IllustrationName` | — | Which illustration to display (required) |
| `colored` | `boolean` | `true` | Coloured or grey/monochrome variant |
| `palette` | `string[]` | — | 11 hex colours, lightest → darkest. Ignored when `colored` is `false` |
| `size` | `number` | `150` | Width and height in pixels |
| `className` | `string` | — | Additional CSS classes |

## Accessibility

- The illustration is decorative, so it is hidden from assistive technology. Put the
  meaning in adjacent text — a heading and a short explanation — rather than in the image.
- Pair it with an action so an empty state tells the reader what to do next.
